# 壁纸可读性：文字垫底设计说明

> 2026-11-14 补充。解决「文字压在用户壁纸上看不清」。

## 问题

聊天背景是用户自选的壁纸（深蓝花纹、金色吊灯、大片窗光）。正文直接压上去，
亮部对比度掉到 2–3:1，低于 WCAG 正文 4.5:1 的门槛。

实测（`test/contrast.mjs`，按真实 alpha 合成后计算）：

| 元素 | 纯深色底 | 壁纸亮部 |
|---|---|---|
| 旁白 `#d8dee9` | 14.01:1 | 4.45:1 |
| 对白 `#7fd3c4` | 10.83:1 | 3.44:1 |
| 神态 `#b39ddb` | 7.90:1 | 2.51:1 |
| 次要信息 `#8b95a5` | 6.25:1 | 1.99:1 |

## 方案取舍

考虑过五种，最终选 **纯色垫底（scrim）**，理由：

| 方案 | 否决原因 |
|---|---|
| 毛玻璃 `backdrop-filter: blur()` | 流式输出时持续重排，实测掉到 20–30fps；且是 AI 生成界面的视觉陈词滥调 |
| 行内垫底 `box-decoration-break` | 中文 500 字段落会碎成几十条断线，观感混乱 |
| 文字描边 `text-shadow` | 14.5px 字号下叠 3–4 层描边，汉字笔画糊成一团 |
| 整屏压暗 | 等于盖死壁纸，违背「保持审美」 |

## 关键数值是怎么定的

**这是验算出来的，不是拍的。**

`test/contrast.mjs` 反推：要让最亮壁纸（`#e8ecf2`）也过 4.5:1

```
对白需要 alpha >= 0.71
神态需要 alpha >= 0.74
```

所以取 **0.75**。（专家建议的 0.68 在纯白壁纸上对白只有 4.20、神态 3.75，不达标。）

但 0.75 会盖住 75% 的壁纸，直接铺纯色就是「黑框」。三个手法找回来：

1. **双色渐变**：左上偏暖（呼应暖色吊灯）、右下偏冷（呼应冷色窗光）
2. **4.5% 噪点纹理**：去掉纯数字色塑料感，质感像布
3. **1px 内高光 + 外描边渐变**：让容器有厚度，不是贴上去的色块

## 最终色板（`test/contrast-final.mjs` 验证）

深色主题，0.75 垫底，最坏情况是纯白壁纸：

| 元素 | 颜色 | 纯白壁纸 | 状态 |
|---|---|---|---|
| 旁白 | `#eef2f8` | 7.53:1 | ✓ |
| 对白 | `#e0b878` | 4.55:1 | ✓ |
| 神态 | `#cdbcf0` | 4.85:1 | ✓ |
| 次要 | `#b6c2d4` | 4.69:1 | ✓ |

**调色记录**：
- 神态从 `#b39ddb` → `#c4b0e8` → 最终 `#cdbcf0`（前两档在纯白壁纸上是 3.07 / 4.32，擦边不过）
- 次要从 `#97a4b6` → `#b6c2d4`（原名在纯白上只有 3.34）

## 亮色主题

亮色主题下走**浅色垫底 + 深色文字**（`--tt-veil-alpha: 0.86`），
而不是继续压暗。

> **踩过的坑**：最初只改了垫底色和 alpha，没有同步换文字色，
> 结果浅字压浅底，纯白壁纸下完全看不见。垫底色必须跟着文字色走。

## 可调参数

宿主或用户想调，改这三个变量即可：

```css
body[data-dsh-tavern-render] {
  --tt-veil-alpha: 0.75;    /* 垫底不透明度，越高越清晰、壁纸越不明显 */
  --tt-veil-radius: 11px;   /* 圆角，8–12px 为宜，再大显得药丸状 */
  --tt-veil-pad: 15px 19px; /* 内边距，水平低于 16px 长中文会贴边 */
}
```

## 仍然存在的边界

- **还没在真机页面里看过效果**。桌面端 Web 页面要鉴权（直连 401），
  无头浏览器进不去。以上都是 `file://` 预览页 + 真实壁纸图验证的。
  装好后需在客户端里刷新页面亲眼确认。
- alpha 是固定值，没有做「按壁纸亮度动态调整」。如果用户的壁纸特别极端
  （纯白、纯亮黄），可能仍需要手动调 `--tt-veil-alpha`。
