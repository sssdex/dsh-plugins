# 验收卡 · 解题·推导（Q15）

用法：**新建空白会话** → 下拉框选「解题·推导」→ 逐题把下面「发给模型」的原文粘进去 → 把模型**原始输出**回贴给我。
我按「准不准 / 看得懂 / 啰不啰嗦」判，不通过就回来继续调 prompt。

---

## 题 ①（一步简单题 — 看会不会硬凑格式、写废话）

发给模型：

```
一个正方形的边长是 7 cm，它的面积是多少？
```

手算标准答案：

```
7 × 7 = 49
49 cm²
```

判据：
- 准：答案 49 cm²（带单位）
- 不啰嗦：不应出现「思路 / 过程 / 讲解」小标题、不应寒暄、不应复述题目、不应列易错点
- 一步就够，别硬拆成多步

---

## 题 ②（3–5 步带公式 — 看多步会不会算错）

发给模型：

```
一个圆柱，底面半径 3 cm，高 10 cm，取 π = 3.14，求它的体积是多少 cm³？若 1 cm³ = 1 mL，它能装多少 mL 水？
```

手算标准答案：

```
底面积 = πr² = 3.14 × 3² = 3.14 × 9 = 28.26 cm²
体积 = 底面积 × 高 = 28.26 × 10 = 282.6 cm³
282.6 cm³ = 282.6 mL
282.6 cm³，即 282.6 mL
```

判据：
- 准：体积 282.6 cm³、282.6 mL（这是硬底线，算错即不通过）
- 逐步：底面积 → 体积 → 单位换算，每步一行，不跳步
- 末尾单独一行给最终答案
- 不啰嗦：无小标题、无四段、无注水讲解、无「验证一下再抄一遍」
